# STRIVO Work — сайт

Двомовний сайт (CZ / UA) для STRIVO Work s.r.o. Чиста статика (HTML/CSS/JS) — без build-кроку.

## Структура

```
/
├── index.html            → чеська версія (ГОЛОВНА, за замовчуванням)
├── cs/index.html          → редирект-заглушка на "/" (для старих посилань, не індексується)
├── uk/index.html          → українська версія
├── robots.txt             → дозвіл індексації + посилання на sitemap
├── sitemap.xml             → карта сайту з hreflang для CZ/UA
├── assets/css/style.css   → дизайн-система
├── assets/js/main.js      → меню, scroll-reveal, лайтбокс, рік у футері
├── assets/img/logo.svg    → логотип
└── assets/img/gallery/    → фото робіт (.jpg + .webp пари)
```

## Продуктивність та UX (нове)

- **WebP + JPEG fallback** для всіх фото галереї — швидше завантаження, менший трафік на мобільному
- **Явні width/height** на всіх фото галереї — сторінка не "смикається" під час завантаження зображень
- **Лайтбокс** — клік на фото в "Reference" відкриває його на весь екран (стрілки ← → або клавіатура, Esc для закриття)
- **Google Maps** — вбудована карта з адресою в розділі "Kontakt"
- **Липка мобільна панель** — на екранах до 768px внизу завжди видно кнопки "Zavolat" і "WhatsApp"
- `rel="preconnect"` до Fontshare — трохи швидше завантаження шрифтів

## SEO

- Чеська версія — на корені сайту (`/`), за замовчуванням, без JS-редиректу за мовою браузера
- `<link rel="canonical">`, `hreflang` (cs / uk / x-default), Open Graph + Twitter Card
- JSON-LD структуровані дані (schema.org GeneralContractor) з адресою, телефоном — **включно з IČO/DIČ у прихованому вигляді для пошукових систем**, без показу цифр відвідувачам на самій сторінці
- `robots.txt` + `sitemap.xml`

**Важливо:** всі абсолютні посилання (canonical, OG, sitemap) вказують на `https://strivowork.cz/` — запрацює одразу після прив'язки домену. До того часу сайт нормально працює й індексується і на `github.io`.

## Дизайн

- Шрифти: **Boska** (заголовки) + **General Sans** (текст) через Fontshare
- Кольори: темно-синій `#0E1B2A` + помаранчевий акцент `#F0A202`
- Секції: hero-фото на весь екран з плаваючими картками, 8 послуг, "чому ми", 13 фото робіт з лайтбоксом, про компанію, карта, 5 кроків співпраці, кар'єра, контакти, розширений footer
- Адаптація під усі пристрої: 4 → 2 → 1 колонка залежно від ширини екрана, липка панель дзвінка на мобільному

## Як викласти на GitHub Pages

1. Створіть новий репозиторій на GitHub, наприклад `strivo-work-web`.
2. У цій папці виконайте:
   ```
   git init
   git add .
   git commit -m "Перший запуск сайту"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/strivo-work-web.git
   git push -u origin main
   ```
3. У репозиторії на GitHub: **Settings → Pages → Source** → оберіть гілку `main`, папку `/ (root)` → Save.
4. Через 1-2 хвилини сайт буде доступний на `https://ВАШ_ЛОГІН.github.io/strivo-work-web/`.

## Як прив'язати домен (.cz)

1. Купіть домен у **WEDOS** або **Forpsi** (зручно для юрособи з IČO).
2. У налаштуваннях DNS домену додайте:
   - 4 записи типу **A** на IP-адреси GitHub Pages:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Якщо хочете `www.strivowork.cz`, додайте ще запис **CNAME**: `www` → `ВАШ_ЛОГІН.github.io`
3. У корені репозиторію створіть файл `CNAME` (без розширення) з вмістом:
   ```
   strivowork.cz
   ```
4. У GitHub → Settings → Pages вкажіть цей домен і зачекайте на видачу SSL-сертифіката (10-30 хв).
5. Після підключення домену додайте сайт у **Google Search Console** та **Seznam Webmaster Tools** і відправте `sitemap.xml`.
