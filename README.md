# STRIVO Work — сайт

Двомовний сайт (CZ / UA) для STRIVO Work s.r.o. Це чиста статика (HTML/CSS/JS) — жодного build-кроку не потрібно.

## Дизайн

- Шрифти: **Boska** (заголовки) + **General Sans** (текст) через Fontshare
- Кольори: темно-синій `#122A38` + зелений акцент `#12B981` (у стилі логотипу)
- Інтерактив: робочий мобільний бургер-меню, плавний скрол до секцій, hover-ефекти на картках і рядках послуг, плавна поява блоків при скролі (scroll-reveal)

## Структура

```
/
├── index.html            → автовизначення мови браузера, редирект на /cs/ або /uk/
├── cs/index.html          → чеська версія
├── uk/index.html          → українська версія
├── assets/css/style.css   → спільна дизайн-система
├── assets/js/main.js      → меню, scroll-reveal, рік у футері
└── assets/img/logo.svg    → логотип
```

## Як викласти на GitHub Pages

1. Створіть новий репозиторій на GitHub, наприклад `strivo-work-web`.
2. У цій папці виконайте:
   ```
   git init
   git add .
   git commit -m "Перший запуск сайту"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/strivo-work-web.git
   git push -u origin main
   ```
3. У репозиторії на GitHub: **Settings → Pages → Source** → оберіть гілку `main`, папку `/ (root)` → Save.
4. Через 1-2 хвилини сайт буде доступний на `https://ВАШ_ЛОГІН.github.io/strivo-work-web/`.

## Як прив'язати домен (.cz)

1. Купіть домен у **WEDOS** або **Forpsi** (зручно для юрособи з IČO).
2. У налаштуваннях DNS домену додайте:
   - 4 записи типу **A** на IP-адреси GitHub Pages:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Якщо хочете `www.strivowork.cz`, додайте ще запис **CNAME**: `www` → `ВАШ_ЛОГІН.github.io`
3. У корені репозиторію створіть файл `CNAME` (без розширення) з вмістом:
   ```
   strivowork.cz
   ```
4. У GitHub → Settings → Pages вкажіть цей домен і зачекайте на видачу SSL-сертифіката (10-30 хв).
